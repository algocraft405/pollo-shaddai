# Pollo Shaddai

Restaurant website for **Pollo Shaddai** — Guatemalan fried chicken in Cincinnati, Fairfield, Indianapolis, and Oklahoma City.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- Home, menu, locations, story, and contact
- English / Spanish toggle
- Order links for each kitchen
